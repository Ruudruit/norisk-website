# No-Risk Autoruitservice Website

Statische HTML/CSS website voor No-Risk Autoruitservice.

## Bestandsstructuur
```
norisk-website/
├── index.html          ← Homepage (video header)
├── diensten.html       ← Dienstenpagina (video header)
├── locaties.html       ← Locatiespagina
├── over-ons.html       ← Over ons pagina
├── contact.html        ← Contactpagina
├── header-poster.jpg   ← Stilstaand beeld voor video header
└── No_Risk_Voorruit_Vervanging.mp4  ← Videobstand (zelf toevoegen)
```

## Video toevoegen
Upload `No_Risk_Voorruit_Vervanging.mp4` naar de hoofdmap van dit project.

## Telefoonnummer aanpassen
Zoek in alle HTML-bestanden naar `+31000000000` en vervang door het echte nummer.
